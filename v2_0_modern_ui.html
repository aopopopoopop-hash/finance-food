Что обновлено в v2.0 по ревью Паши:
  • Добавлен переключатель месяцев и лет (◀ Сентябрь | Октябрь | Ноябрь ▶). При наступлении нового месяца бюджет автоматически считается с нуля, сохраняя прошлые месяцы в архиве.
  • В раздел «3. Аналитический отчет» встроена интерактивная календарная сетка по дням. Клик по любому дню показывает все траты именно за этот календарный день.
  • Убраны черные «программистские» окна с главного экрана, добавлен мобильный нижний таб-бар.

Как обновить файл на GitHub Pages:

  1. Сохраните этот обновленный код на компьютер как файл index.html.
  2. В своем репозитории на GitHub нажмите Add file → Upload files, перетащите новый index.html и нажмите Commit changes.
  3. Через 40–60 секунд обновите страницу по вашей ссылке — новая версия 2.0 заработает на телефонах и компьютерах!
